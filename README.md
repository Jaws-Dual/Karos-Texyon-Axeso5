# Karos-Texyon-Axeso5
Tools(Редакторы), Servers(Сервера), Clients(Клиенты)

# Возможности
  1) Рукопожатие с клиентом — полный цикл от логина до выбора сервера;
  2) Сборка пакетов — все функции написаны с нуля, без шаблонов и внешних файлов;
  3) Полностью восстановлено шифрование — все варианты, использовавшиеся до 2021 года включительно;
  4) Готовые сборки серверов GATE, MID, GAME — полный комплект для развёртывания;
  5) Сборки от подключения до входа в мир — можно пройти путь от логина до появления в игровом мире;
  6) Реализованные игровые механики — базовые взаимодействия, тестовые мобы, стартовые элементы;
  7) Шаблоны проектов на C#, C++, Python;
# Редакторы основных игровых файлов:
  1) *.lod_ (языковые файлы);
  2) *.lod (скиллы);
  3) *.ten (таблицы/конфигурация).

# Быстрый старт
  1) Соберите сервер через или вручную;
  2) Запустите серверы (GATE, MID, GAME)\(PORTAL, GAME);
  3) Подключитесь клиентом — сервер появится в списке;
  4) Выберите канал и войдите в мир.
